IoT & Automation

Cold Storage Unit

Overview

An Arduino-based automated cooling system designed to monitor ambient temperature and dynamically control a cooling fan to maintain optimal preservation conditions for vegetables, significantly reducing spoilage in commercial and home storage environments.

The system continuously reads temperature data from a sensor, compares it against configurable thresholds stored in firmware, and switches the fan on or off via a relay module — creating a closed-loop automated cooling cycle without any human intervention.

Key Features

  • Real-time temperature monitoring using a digital temperature sensor (DS18B20/DHT series)
  • Relay-controlled DC fan activation based on programmable upper/lower temperature thresholds
  • Firmware written in C/C++ using Arduino IDE with configurable safety thresholds
  • Compact embedded design — no external power or cloud dependency required
  • Reduces post-harvest vegetable spoilage through consistent automated cooling

Technologies Used

Arduino UNO C / C++ Arduino IDE Temperature Sensor Relay Module DC Cooling Fan Embedded Systems

Smart Agriculture

Smart Irrigation System

Overview

An IoT-based automated irrigation system that continuously monitors soil moisture levels and automatically activates or deactivates a water pump to deliver the precise amount of water each plant needs — preventing both under-watering and wasteful over-watering.

The system uses capacitive soil moisture sensors buried in the plant medium, reading analog voltage levels that correspond to moisture percentage. The Arduino microcontroller evaluates these readings against defined dry/wet thresholds and controls a relay-driven water pump accordingly.

Key Features

  • Real-time soil moisture sensing with capacitive moisture sensors for accurate, corrosion-resistant readings
  • Automatic pump activation when moisture drops below a configurable dry threshold
  • Automatic pump cut-off once optimal moisture level is reached, preventing root rot from over-watering
  • Low-power design — Arduino operates in idle mode between sensor polling cycles
  • Fully offline embedded system — no Wi-Fi or cloud services required for autonomous operation
  • Scalable to multiple sensor zones for larger garden or agriculture setups

Technologies Used
